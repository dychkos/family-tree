# Родинне дерево

Статичний сайт для GitHub Pages. Без збірки та залежностей.

## Структура

- `index.html` дерево з переміщенням, масштабом і пошуком
- `person.html?id=<id>` сторінка людини
- `data/family.js` усі дані родини (формат описано на початку файлу)
- `photos/` світлини

## Локальний перегляд

Відкрити `index.html` у браузері. Сервер не потрібен.

## Публікація

1. Створити репозиторій на GitHub і запушити гілку `main`.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
3. Сайт буде доступний за адресою `https://<user>.github.io/<repo>/`.

## Приватність

GitHub Pages публічний. Дані живих людей (точні дати народження, адреси) варто скорочувати до року або не вказувати.
